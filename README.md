# Mohammed Shaheem | Home Page

A personal home page built with HTML, CSS and JavaScript.

**Student:** Mohammed Shaheem
**College:** Sahyadri College of Engineering and Management
**Semester:** 3rd, Computer Science Engineering

## Features
- Responsive layout (works on phone and desktop)
- Dark and light theme toggle (choice is remembered)
- Typing effect on the role line
- Navigation bar that highlights the current section

## Files
- `index.html` : page structure
- `style.css` : colours, fonts and layout
- `script.js` : theme toggle, typing effect, active menu link

## Run locally
Open `index.html` in any browser.
